Privacy

This page covers naumanbuilds.com, demo.naumanbuilds.com and the two demos you can try there, a voice agent and a WhatsApp bot for Northside HVAC & Plumbing. Northside is a made-up company. I run both demos myself, so please use made-up details when you try them.

The websites

Neither site uses cookies, analytics or any tracking. The pages are hosted on GitHub Pages, and GitHub may keep its own server logs.

The demo page saves one random ID in your browser's local storage. The call limits use it to tell repeat visits apart. It isn't linked to anything else about you.

The voice demo

Calls go through Retell, which runs the voice agent and records each call. The agent says so at the start of the call.

What you say on a call can end up in a few places: the recording and transcript at Retell, a booking or callback request in a Google Calendar and a Google Sheet, and an alert email to my inbox when something needs a person. For the browser call limits I keep a short hash of your IP address with the call record, not the address itself.

I delete rows in the Sheet by hand. Recordings and transcripts are deleted when you ask (see below).

The WhatsApp demo

Messages you send to the demo's WhatsApp number come to my automation server (n8n) through Meta's WhatsApp Cloud API. Meta handles them under its own terms.

I keep your WhatsApp number and the conversation for 7 days, so a person can read it if the bot hands the chat over. Then it's deleted automatically. The raw message data, which includes your WhatsApp name, also sits in n8n's run logs, and those are deleted after 7 days too.

If you ask for a callback, the name, number and problem you type go into the same Google Sheet as the voice demo. Alert emails to my inbox can include the recent messages, but only the last two digits of your WhatsApp number.

Who else handles the data

Retell (voice calls), Meta (WhatsApp), Google (Calendar and Sheets), Cloudflare (connects the demos to my server), Zoho (my email) and GitHub (hosts the pages). I don't sell or share the data with anyone else, and I don't use it for marketing.

Getting your data deleted

Email nauman@naumanbuilds.com with the rough time of your call, or the WhatsApp number you messaged from. I'll delete the recording, transcript, Sheet rows, messages and alert emails that belong to you, and reply when it's done.
